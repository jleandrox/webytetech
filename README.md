# WeByte Tech — Portfólio

Projeto do portfólio da WeByte Tech com HTML, CSS e JavaScript separados.

## Estrutura

```text
webyte-tech-project-completo/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Como abrir no VS Code

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Observação

Os ícones das tecnologias usam Simple Icons via CDN. Os links de LinkedIn, GitHub e e-mail ainda estão como placeholders para você substituir.
